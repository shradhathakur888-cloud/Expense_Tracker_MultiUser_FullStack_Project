# Multi-User & Duo Household Expense Tracker

**Designed & Developed by Shradha Thakur**

A complete full-stack web application designed for personal and joint multi-user expense tracking, cash flow velocity, and fair-share budget settlements between partners or roommates.

---

## What's New in This Version

- **Amounts in Indian Rupee (₹)**: All currencies, balances, inputs, and chart axes are strictly in Indian Rupees (₹) with Indian number formatting (e.g. `₹75,000.00`).
- **Bright Mode & Dark Mode**: Easily toggle between a crisp, sunny Bright Mode (☀️) and sleek Dark Mode (🌙) right from the top navigation bar.
- **Zero Fake Data**: No fabricated demo transactions or dummy purchases. Accounts start completely clean so your history only reflects your genuine entries.
- **Ease of Use**: Large, direct quick-action buttons right on top:
  - `+ Record Expense (खर्च)`
  - `+ Record Income (कमाई)`
  - `Print History Statement`
- **Record History & Print History**: Full transaction ledger with a dedicated "Print History" button that outputs a printable, statement-ready report with clean margins and headers.
- **History Bar Graph**: Dedicated historical bar graph displaying inflows vs expenditures over time in Indian Rupees (₹).
- **Two People in One Account**: Add your partner or roommate to split joint expenses 50/50.

## Quick Start

1. Start server:
   ```bash
   cd backend
   python app.py
   ```
   *(Or double-click `run.bat`)*

2. Open in browser:
   **[http://localhost:5000](http://localhost:5000)**
